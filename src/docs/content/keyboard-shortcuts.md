# Keyboard Shortcuts

Shortcuts act only when the relevant feature is enabled and focus is not inside an editor that needs native key behavior.

## Selection

| Input           | Action                         |
| --------------- | ------------------------------ |
| Click           | Select a cell                  |
| Drag            | Extend a configured range      |
| Shift+click     | Extend from the anchor         |
| Arrow keys      | Move the active cell           |
| Shift+Arrow     | Extend the selection           |
| Tab / Shift+Tab | Move horizontally              |
| Ctrl/Cmd+Home   | Jump to the first visible cell |
| Ctrl/Cmd+End    | Jump to the last visible cell  |

## Editing

| Input              | Action                                 |
| ------------------ | -------------------------------------- |
| Double-click       | Edit an editable cell                  |
| Enter              | Start editing, or commit and move down |
| Tab / Shift+Tab    | Commit and move horizontally           |
| Escape             | Cancel editing                         |
| Alt/Option-click   | Quick edit                             |
| Alt/Option-drag    | Select partial text for quick edit     |
| Delete / Backspace | Clear editable selected cells          |

## Clipboard and History

| Input            | Action                             |
| ---------------- | ---------------------------------- |
| Ctrl/Cmd+C       | Copy the selected rectangle as TSV |
| Ctrl/Cmd+V       | Paste at the active cell           |
| Ctrl/Cmd+Z       | Undo                               |
| Ctrl/Cmd+Shift+Z | Redo                               |

## Pointer Gestures

| Input                    | Action               |
| ------------------------ | -------------------- |
| Drag fill handle         | Repeat source values |
| Drag header edge         | Resize a column      |
| Double-click header edge | Reset column width   |

## Platform Notes

Use Command on macOS and Control on Windows or Linux. Option on macOS maps to Alt on other platforms.
